API Provider Setup

Follow these step-by-step instructions to securely generate API tokens for your preferred AI providers.

🧠 OpenAI
Get API Key →

Powers the core AI tutor, syllabus extraction, lesson generation, and high-quality TTS options.

  1. Sign in to the OpenAI platform and navigate to the API Keys page.
  2. Click "Create new secret key".
  3. Give it a name (e.g., "Aura Study") and click Create.
  4. Copy the generated key (it starts with sk-...) and save it securely.
✨ Google Gemini
Get API Key →

Used for lightning-fast multi-modal reasoning and dynamic lesson generation.
Note: Google AI Studio requires users to be 18+. You can ask your parents to create an API key for this app.

  1. Go to Google AI Studio and sign in with your Google account.
  2. Click "Get API key" in the left navigation menu.
  3. Click "Create API key" and select a project (or create a new one).
  4. Copy the generated key and save it securely.
🌐 OpenRouter
Get API Key →

Access dozens of top-tier AI models (including Claude 3, Llama 3, and more) through a single unified API.

  1. Sign in to OpenRouter and go to the Keys page.
  2. Click "Create Key" and assign it a memorable name.
  3. Copy the generated key and save it securely.
🔊 ElevenLabs (Optional)
Get API Key →

Provides ultra-realistic AI voices for the Read Aloud feature. (Aura also supports free Edge TTS out of the box!)

  1. Create an account on ElevenLabs.
  2. Click on your profile picture in the bottom left corner and select "Profile + API key".
  3. Click the eye icon to reveal your API key and copy it securely.
